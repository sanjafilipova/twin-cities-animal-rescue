# Twin Cities Animal Rescue Website

A responsive, multi-page website I created for Twin Cities Animal Rescue as part of my Introduction to Web Development course.

## About the Project

The goal of this project was to create a welcoming and easy-to-use website that helps visitors learn about animal rescue and find ways to get involved through adoption, fostering, volunteering, and donations.

I designed and developed the website using HTML, CSS, and JavaScript, focusing on clear navigation, responsive layouts, accessibility, and interactive features.


## Technologies Used:

- **HTML5** – Website structure and content

- **CSS3** – Styling, Flexbox, and responsive design

- **JavaScript** – Interactive features and form validation

- **localStorage** – Saving user selections

- **GitHub Codespaces** – Development environment

- **GitHub Pages** – Website hosting


## Website Pages:

- **Home:** Introduces the rescue, its mission, and its impact.

- **Services:** Explains adoption, fostering, and volunteer opportunities.

- **About:** Shares the rescue's story, values, and community partnerships.

- **Contact:** Includes an interactive interest form with validation.

## Key Features:

- Responsive layouts for desktop and mobile devices

- Consistent navigation across all four pages

- Interactive messages based on the visitor's selected interest

- Form validation with helpful error messages

- Browser storage that remembers selected interests and availability

- Accessible form labels and organized page headings

## What I Learned

This project helped me become more comfortable building a complete website from the beginning. I gained hands-on experience organizing multiple HTML pages, creating responsive layouts, writing JavaScript functions, and troubleshooting problems during testing.

One of the biggest challenges was getting the Contact form to work correctly. Solving that problem helped me understand why testing user interactions is just as important as making a website look good.

## Future Improvements

In the future, I would like to add individual profiles for adoptable animals so visitors can learn more about available pets before contacting the rescue.
